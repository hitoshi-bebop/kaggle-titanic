# Titanic Survival Prediction

## 1. Project Objective
タイタニック号の乗客情報から、生存したかどうかを予測する。

## 2. Machine Learning Problem
- Learning Type: Supervised Learning
- Problem Type: Binary Classification

## 3. Target Variable
- Variable: Survived
- 0: 死亡
- 1: 生存

## 4. Features
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

## 5. Evaluation Metric
Accuracy（正解率）

## 6. Dataset
- train.csv: 891 rows
- test.csv: 418 rows
